# Altamayoz School Database Project

## Overview

A centralized relational database built with MySQL to manage the data of a complete educational system. This project covers three main entities: **Students**, **Teachers**, and **Subjects**.

This project was developed as a practical application of the **SQL 101** course offered by **Satr Platform**, part of **Tuwaiq Academy** — a course designed to introduce the fundamentals of SQL in managing databases, including storing, displaying, updating, and deleting data.
